mc_dualstack_check API

API for checking Minecraft servers over IPv4 and IPv6, Bedrock and Java. Fully dual-stack. Free to use; results are cached for 60 s and clients are rate limited.

  • Web interface
  • API documentation
  • Source code (GitHub)
GET /ping?ip=<addr>&port=<n>&edition=bedrock|java[&host=<name>]
GET /ping?host=<name>&family=4|6&port=<n>&edition=bedrock|java
GET /health
curl "https://mcdscheck-api.poggensee.it/ping?ip=2001:db8::1&port=19132&edition=bedrock"
Limits per client: 10 systems per minute, 4 health requests per 7 s, then a 60 s cooldown (429).
No logging beyond access logs.
